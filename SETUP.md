# Setup

1. Put everything in this folder into your profile repository (`deprimus01/deprimus01`) and push to `main`.
2. Make sure the hidden `.github` folder is included. Run `ls -a` before you push and check that `.github` is listed.
3. The **Contribution snake** workflow runs on push and every 6 hours. It saves the animation on a branch called `output`, which the README loads. If it fails with a permissions error, go to **Settings, Actions, General, Workflow permissions** and choose **Read and write permissions**, then run it again.
4. Set your GitHub bio from `BIO.txt`.

Light mode: every graphic ships with a `-light.svg` variant that GitHub shows automatically to visitors using the light theme.
